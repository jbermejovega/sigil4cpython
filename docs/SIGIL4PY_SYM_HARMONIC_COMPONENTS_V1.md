# SIGIL4PY SYM — Plural Typed Harmonic Components V1

Canonical candidate: `SIGIL4PY_SYM_PLURAL_HARMONIC_COMPONENTS_V1`.

Mathematical scope: finite real cochain complexes with standard positive
definite inner products. The library checks dimensions and d²=0, then
constructs Hodge Laplacians and exact nullspaces with SymPy.

Facets:
- KLASS: typed degree and cochain dimensions
- GLASS: exact harmonic representatives and cohomology dimensions
- ASS: plural component assembly (not a proven categorical tensor)
- SASS: optional artistic preparation
- SASSY: optional color-preserving rendering
- KULA: plural typed envelope

The 5-cycle has C0=R^5, C1=R^5 and no C2. Hence b0=b1=1.
This is a graph, not a filled pentagon. Twisted local systems require
separate boundary matrices and explicit transport witnesses.

No Sage, polymake, visualization, or MPI is executed by this module.
SymPy is an optional external library; copyright and licenses remain separate.
No general polykategory coherence theorem is claimed.
