## Distinct legal surfaces

1. **Software**: original `sigil4cpython` code follows the license
   actually granted by its rights holders. `pyproject.toml` currently
   declares Apache-2.0. A metadata declaration does not relicense
   third-party code or override the repository's other notices.
2. **SymPy**: optional external symbolic engine; retain its BSD-3-Clause
   licensing and attribution. It is not owned by SIGIL.
3. **KRONE textbook, explanations, exercises**: propose CC BY-SA 4.0
   *only for original material specifically marked as released under

   all rights reserved.
4. **PACA ARTE**: authored illustrations, compositions, performances,
   narratives, games, game assets and source material remain copyrighted
   by their respective authors. No blanket Creative Commons grant.
5. **Third-party assets**: preserve provenance, license, attribution,
   trademarks and restrictions. A fork is not an authorship claim.

## Creative Commons overlay (content only)

An overlay is a per-artifact manifest and notice, not a license applied
retroactively to the entire repository. `CC BY-SA 4.0` requires
attribution, license link, indication of changes and share-alike for
adaptations within its scope. An artifact without explicit authorization
is `ALL_RIGHTS_RESERVED` / `HOLD_QUNO`.

The license notice should identify the exact work, author/rightsholder,
version, source lineage, modifications, license URI and permissions.

## UAP4 equivalent exchange

`RESOURCE`, `COST`, `BOUNDARY`, `WITNESS` are independent ports.
Numerical balance does not certify physical, legal or ethical equivalence.
The PACA GUAPA norm protects reciprocal consent and attribution.

## SAFE_TO_SHIP vessel gate

The `SAFE_TO_SHIP` tag is reserved until all gates have evidence:
- isolated and full-package tests;
- Python/C build and CLI packaging validation;
- dependency version and security audit;
- original work ownership and third-party license audit;
- artwork and textbook release consent, artifact by artifact;
- reproducibility and teaching answer checks;
- independent review and explicit human release authorization.

The existing V1 code and five authored tests do not establish those gates.
No release, public distribution, CI run or game runtime is implied.
